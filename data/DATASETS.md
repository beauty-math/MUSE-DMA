# Benchmark data

This directory contains the actual benchmark files used by the release. It is
not a placeholder scaffold.

| Directory | Drugs | Microbes | Known associations | Raw source |
|---|---:|---:|---:|---|
| `IMDAD/` | 1,209 | 172 | 2,268 | PCMDA `mdd.rar` |
| `aBiofilm/` | 1,720 | 140 | 2,884 | SCSMDA aBiofilm bundle |
| `MDAD2470/` | 1,373 | 173 | 2,470 | SCSMDA MDAD bundle |

Each dataset contains:

- `raw/`: the upstream benchmark files;
- `processed/`: canonical names and positive association tables generated by
  `scripts/prepare_data.py`;
- `folds/fold_1` through `fold_5`: explicit train, validation, and test pair
  files used by every compared method;
- `dataset_manifest.json`: dimensions and identifier conventions.

All pair CSV files use zero-based `drug_idx0` and `microbe_idx0`. Canonical
association tables also retain one-based source IDs for traceability.

## Data terms

The repository's MIT license covers the MUSE-DMA source code only. The bundled
benchmark files retain the provenance and terms of their upstream sources.
No separate data-license file was present in either source repository at the
commits recorded in `docs/DATA_PROVENANCE.md`. Users should consult and cite
the original datasets and source articles when redistributing or reusing them.
